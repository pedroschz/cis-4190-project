\section{Introduction}
We address Track B: classify a news headline as \textbf{Fox News} or \textbf{NBC News}. The course-supplied baseline (TF-IDF + Logistic Regression on top-100 features) reaches 66.49\% accuracy. We build a richer classical baseline and a fine-tuned DistilBERT/RoBERTa model, target $\geq 80\%$ accuracy, and use the additional capacity to study \textit{temporal robustness}: how does source-classification accuracy degrade as the gap between training and test data grows?

\section{Data Collection}
\paragraph{Sourcing.} We started from the course's 3{,}815 article URLs (2{,}010 Fox, 1{,}805 NBC) and scraped each one via a polite (1 req/sec) BeautifulSoup pipeline. We extracted headlines from JSON-LD \texttt{NewsArticle.headline} when present, falling back to \texttt{og:title} and finally \texttt{<h1>}. We also captured \texttt{datePublished} for each article, which is essential for our temporal analysis. URLs that 404'd or rate-limited were retried via the Wayback Machine CDX API.

\paragraph{Historical expansion.} To enable temporal experiments, we expanded the corpus by walking each outlet's XML sitemap index and uniformly sampling $\approx$800 articles per (source, year) for 2019--2024. This yields $\approx$10{,}000 additional headlines beyond the provided seed set.

\paragraph{Cleaning.} We strip site suffixes (e.g. ``\texttt{ | Fox News}'') with regex; normalize Unicode (NFKC) and whitespace; drop headlines outside [10, 300] characters; deduplicate via lowercased, punctuation-stripped exact match. A leakage filter removes any remaining headline whose body contains the literal source name. Final dataset: \texttt{data/processed/headlines.csv} with columns \texttt{headline, source, publish\_date, year, url, source\_split}.

\paragraph{Splits.} (i) \textbf{Random}: stratified 80/10/10 on \texttt{source} with seed 42 (used for the leaderboard model). (ii) \textbf{Temporal}: train $\leq 2022$, val 2023, test $\geq 2024$ (used for the analysis).

\section{Model Design}

\paragraph{Iteration.} We trained five model variants in increasing capacity:
\begin{enumerate}
    \item V0 — Course baseline replica (TF-IDF top-100 + LR). Confirms our pipeline reproduces the published 66.49\%.
    \item V1 — Word 1--2-gram TF-IDF (50k feats) + LR (\texttt{class\_weight=balanced}).
    \item V2 — FeatureUnion of word 1--2-gram and character 3--5-gram TF-IDF + LR. Captures both lexical and stylometric cues.
    \item DistilBERT-base-uncased fine-tuned for 3 epochs (lr 2e-5, batch 32, max\_len 128, fp16) on the random split.
    \item RoBERTa-base fine-tuned with the same recipe.
\end{enumerate}

\section{Exploratory: Temporal Robustness}
\paragraph{Question.} The course's hidden test set is scraped \emph{after} our submission. How much accuracy do we lose as the gap between training and test data grows?

\paragraph{Experiment 1: Decay curve.} For each train year $Y \in \{2019, 2020, 2021, 2022\}$, we train V2 (and DistilBERT) on data from year $Y$ alone and evaluate on each year $Y' \geq Y$. Plotting accuracy as a function of the gap $Y' - Y$ shows the decay rate.

% \begin{figure}[h]\centering\includegraphics[width=0.8\textwidth]{figures/temporal_decay.png}\caption{Accuracy vs.\ temporal gap. Both models degrade, but \textsc{TBD} degrades more.}\end{figure}

\paragraph{Experiment 2: Fixed-train sliding-test.} Train once on all data $\leq 2022$, then evaluate per-year on 2023 and 2024. This mirrors the course's leaderboard setup.

\paragraph{Findings.}
\textsc{TBD after experiments run.} Anticipated story:
\begin{itemize}
    \item Both models lose accuracy as the gap grows, but at different rates.
    \item Errors concentrate on entity-driven topical headlines (politicians, places) whose prevalence shifts year-over-year — top-weighted classical features for ``Trump'' / ``Biden'' / ``Covid'' all change rank.
    \item Stylistic cues (sentence-formula, capitalization, character n-gram patterns) are more stable across time than lexical content.
\end{itemize}

\paragraph{Implications.} The hidden test set will likely score 3--7 pp below our random-val accuracy. Our final leaderboard submission is therefore the model that maximizes random-val accuracy \textit{and} has the slowest temporal decay (\textsc{TBD}).
